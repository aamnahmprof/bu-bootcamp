BU MS - Foundations Bootcamp

This repository contains all my work from the Software Engineering Bootcamp through Boston University.

## Program Structure
* Module 1 - Development Environment & First Programs
* Module 2 - Programming Fundamentals
* Module 3 - Data Structures & Object Oriented Basics

* Module 5 - Unit Testing with JUnit
* Module 6 - Python Fundamentals & Data Science Applications

There will be a folder dedicated to each module, with all resources and code contained inside those.
